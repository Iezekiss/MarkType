# МШП · Код на скорость

Клавиатурный тренажёр для младших школьников, занимающихся в Mark.Online. Ребёнок видит готовый текст и перепечатывает его. Приложение измеряет скорость и точность, но не исполняет код и не проверяет понимание команд.

## Запуск

Нужен Node.js 20.19+ в ветке 20 либо 22.12+ и менеджер пакетов. Разработка проверена на Node.js 24.19.0 и pnpm 11.19.0.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Открыть `http://127.0.0.1:5173`. Можно использовать и npm: `npm install`, затем `npm run dev`. Для воспроизводимой установки используется включённый `pnpm-lock.yaml`.

```sh
pnpm test          # автоматические проверки
pnpm test:watch    # тесты при изменениях
pnpm build        # проверка TypeScript и production-сборка
pnpm preview      # локальный просмотр собранной версии
```

## Размещение статического сайта

После `pnpm build` загрузить **содержимое** папки `dist/` на любой статический HTTP(S)-хостинг, сохранив каталог `assets/`. На хостинге не нужны Node.js, сервер приложения, база данных, ключи API или регистрация. Можно разместить в подпапке: Vite использует относительный `base: './'`. Перенаправления маршрутов не нужны — экраны переключаются внутри одной страницы.

Не открывайте `dist/index.html` через `file://`: загрузка ES-модулей требует HTTP(S). Шрифты и все зависимости включены в сборку; во время тренировки нет запросов к внешним сервисам. Это обычный статический сайт, без установки PWA и офлайн-кэша для первого открытия без сети.

## Как пользоваться

1. Выбрать «Команды», «Алгоритмы» или «Свой текст» и время 30, 60 либо 120 секунд.
2. Нажать «Начать». После 3–2–1 одновременно открывается образец и запускается таймер.
3. Вводить каждый символ в поле под образцом. После полного совпадения следующий образец появляется автоматически.
4. Посмотреть результат, повторить тренировку или изменить настройки.

Изначально выбраны «Команды» и 60 секунд. Настройки сохраняются на устройстве. Все три режима доступны сразу.

В режиме «Свой текст» преподаватель может вставить готовый фрагмент. CRLF и CR преобразуются в LF, каждая табуляция — в четыре обычных пробела. Другие пробелы, пустые строки и регистр сохраняются. Итоговый текст показан до старта. Исходный текст не записывается в localStorage и остаётся в памяти до перезагрузки/закрытия страницы. Текст из одних пробелов не запускается. Передавайте в это поле только учебный материал, без имён и контактов.

## Правила ввода и подсчёт

- Проверяется фактически полученный символ `KeyboardEvent.key`, а не расположение клавиши. Проверка учитывает регистр и различает латиницу и кириллицу.
- Верный символ добавляется в префикс. Неверный увеличивает счётчик ошибок, кратко выделяет текущую позицию и не сдвигает её. При кириллице вместо ожидаемой латинской буквы появляется подсказка раскладки.
- Backspace удаляет один принятый символ только текущего образца. Завершённые образцы и прежние ошибки сохраняются.
- Пробел и требуемый Enter считаются отдельными символами. После Enter сразу за двоеточием появляется отступ (в алгоритмах — четыре пробела). Каждый следующий Enter сохраняет отступ предыдущей строки. Для выхода из цикла нужно удалить четыре пробела клавишей Backspace; после этого новые строки начинаются без отступа. Перед командой без отступа в образце тренажёр подсказывает, сколько пробелов осталось удалить. Автоматические пробелы и их удаление не считаются попытками и не повышают скорость. Другие пробелы, парные скобки и кавычки вводятся вручную.
- Служебные клавиши и навигация не считаются попытками. Tab позволяет перейти к другим элементам. Автоповтор удерживаемой клавиши игнорируется.
- В тренировочном поле блокируются обычная вставка, Ctrl/Cmd+V и drag-and-drop. Поле подготовки разрешает вставку. Это защита от обычного копирования, а не защита от программной подмены событий.
- Единственная точка начисления — keydown; input не начисляет символы повторно. Требуется клавиатура, выдающая события клавиш. Мобильные экранные клавиатуры, IME и диктовка не являются поддерживаемыми способами набора; на узком экране можно использовать внешнюю клавиатуру.

**Скорость, зн/мин** = `(число вручную набранных символов завершённых образцов + число вручную набранных символов правильного префикса текущего образца) / активные минуты`. Итог округляется до целого. Unicode-символы считаются по кодовым точкам. Удаление ручного символа уменьшает зачтённый префикс, повторный набор удалённой части не завышает скорость. Удаление автоматически поставленного пробела не уменьшает скорость; если набрать его заново вручную, он учитывается как ручной ввод.

**Точность** = `правильные попытки / (правильные + ошибочные попытки) × 100%`, до одного десятичного знака. Повторный правильный ввод после Backspace остаётся правильной попыткой, а Backspace и служебные клавиши не являются попытками. История ошибок не стирается. Пока попыток нет, скорость и точность отображаются как «—», в том числе на результате; такая сессия не устанавливает рекорд.

Таймер использует `performance.now()`, а не число срабатываний интервала. Каждый ввод дополнительно проверяет время: после истечения длительности он не засчитывается, даже до обновления интерфейса.

Esc, кнопка «Пауза», потеря фокуса окна и скрытие вкладки приостанавливают тренировку. Образец и ввод убираются из DOM под непрозрачным состоянием паузы. Возврат не запускает тренировку: нужно нажать «Продолжить» и дождаться нового отсчёта. Пауза и отсчёты не входят в активное время.

## Команды и случайные алгоритмы

Синтаксис предоставлен пользователем 07.10.2026. Режим «Команды» содержит `go()`, `left()`, `right()`, `jump()`, `put()`, `take()` и шесть вариантов `paint`: `paint(red)`, `paint(blue)`, `paint(white)`, `paint(yellow)`, `paint(purple)`, `paint(green)`. Цвет записывается без кавычек.

Режим «Алгоритмы» создаёт новые фрагменты по ходу тренировки: 12–30 строк со случайными командами, цветами и циклами. Чередуются в случайном порядке три вида фрагментов: последовательности команд, сочетания команд с циклами и последовательности циклов. Число повторений выбирается от 2 до 10. По предоставленному скриншоту заголовок цикла заканчивается двоеточием, а команды тела располагаются ниже с отступом в четыре обычных пробела:

```python
go()
for i in range(4):
    jump()
    right()
    right()
paint(red)
```

Число команд в теле и порядок команд меняются случайно. Повторы соседних команд разрешены, как в примере пользователя. Циклы перемешиваются целыми блоками, сохраняя тело под своим заголовком. Соседние полные образцы не совпадают; при повторном старте создаются новые сочетания. Образец остаётся неизменным до полного набора. Это учебный текст для перепечатывания; приложение не исполняет код и не оценивает алгоритмическую осмысленность сочетаний.

- `src/data/catalog.ts`: точные тексты и поля `id`, `title`, `type`, `category`, `text`, `source`, `status`.
- `src/data/algorithms.ts`: генератор алгоритмов; диапазоны и версия его правил находятся в `ALGORITHM_RULES` в каталоге. Фиксированные фрагменты каталога служат примерами, а не ограниченным списком тренировочных заданий.
- `src/data/pending-commands.ts`: русские названия команд, ожидающих сверки. Этот файл не подключён к тренировке.

Для добавления подтверждённого материала:

1. Получить точный синтаксис от преподавателя или сверить его по справочнику/редактору Mark.
2. Добавить запись в `catalog` с уникальным `id`, `type: 'command'` или `'fragment'`, точными пробелами/переносами, ссылкой или названием документа и датой в `source`, `status: 'confirmed'`.
3. Изменить `CATALOG_VERSION` при новой редакции материала. Добавленные команды автоматически доступны генератору. При изменении способа построения алгоритмов обновить также версию `ALGORITHM_RULES`.

`status: 'pending'` и пустые строки исключаются. `confirmed` означает предоставленный точный синтаксис, `generated` — сочетание команд, `provided` — собственный материал преподавателя. Категория и источник хранятся вместе с данными.

В режиме «Команды» перед сессией и после исчерпания колода перемешивается Fisher–Yates. Дубли одинакового текста объединяются; при двух и более разных текстах последний и первый образцы на границе колод не совпадают. Один образец может повторяться. Пустая колода не запускается.

## История и конфиденциальность

Для алгоритмов и собственных образцов с отступами ключ рекорда включает версию правил автоматического отступа. Их прежние рекорды сохраняются отдельно, поскольку правила набора менялись. Условия режима «Команды» не меняются.

В localStorage сохраняются режим/длительность, последние 20 **завершённых** тренировок и лучшие результаты по условиям. Сохранения каждого нажатия нет. Данные не отправляются на сервер; имена, контакты и аналитика не собираются. При запрете localStorage приложение продолжает работать и сообщает, что результат сохранить не удалось.

Рекорд относится к режиму, длительности, версии и точному составу текстов. Для случайных алгоритмов учитываются также весь набор команд и правила генерации: разные случайные задания при одинаковых правилах сравнимы. Рекорды прежнего набора сохраняются отдельно. Для состава используется 128-битный отпечаток четырёх независимых 32-битных аккумуляторов, чтобы не сохранять пользовательский текст; это ключ сравнения, не криптографическая защита. При одинаковой скорости предпочтительнее большая точность. Рекорд хранится отдельно от истории последних 20 сессий, поэтому не исчезает при её автоматическом сокращении. Кнопка «Очистить историю» удаляет историю и рекорды после подтверждения, сохраняя настройки. Подпись в интерфейсе — «Рекорд на этом устройстве».

## Доступность и внешний вид

Настоящие radio, button и textarea, видимый фокус, доступное название поля, нет ловушки Tab. Текущая позиция имеет фон, подчёркивание и курсор. Автоматическая прокрутка перемещает содержимое полей, не страницу. Анимации и звуки отсутствуют, учтён `prefers-reduced-motion`.

Интерфейс автоматически использует ширину окна до 1760 px. В тренировке рабочая область занимает доступную высоту окна: образец и ввод расположены рядом при ширине от 900 px и друг над другом в узкой панели. На реальном размере панели 320×594 оба поля видны одновременно; кнопка запуска также доступна без прокрутки. Код оформлен как редактор: белый фон, нумерация строк, подсветка ключевых слов и чисел, выделение текущей строки, точки только в отступах. Шрифт алгоритмов — 18–24 px. Длинные строки и алгоритмы прокручиваются внутри полей; курсор и номера строк следуют за набором. Масштаб браузера вручную менять не требуется.

Перед оформлением просмотрен актуальный [сайт МШП](https://informatics.ru/) 07.10.2026: синие акценты, округлые заголовки, крупные кнопки. Здесь используется самостоятельная адаптация для тренажёра с Nunito, локальными шрифтами и текстовой подписью; это не утверждение об официальном брендбуке. Код набирается моноширинным шрифтом без лигатур.
