# Проверки — 07.10.2026

## Текущее обновление: сохранение и ручное снятие отступа

- Каждый Enter переносит отступ предыдущей строки. После двоеточия начинается новый уровень отступа; в алгоритмах — четыре пробела. Для выхода из цикла нужно удалить их вручную, после чего следующие строки идут без отступа.
- Если отступ уже не нужен по образцу, он остаётся в поле до удаления через Backspace. Подсказка показывает число оставшихся пробелов. Эти пробелы и их удаление не меняют скорость или точность.
- Добавлены проверки продолжения нескольких команд, четырёх Backspace, следующих строк без отступа, нового цикла, частичного снятия отступа, паузы и точных метрик. До реализации новые проверки падали; теперь проходят все **55 тестов в 6 файлах**. TypeScript и production-сборка проходят.
- В браузере набран `for i in range(2):`, затем `go()` и `right()` с Enter: отступ на обеих строках появился сам. После следующего Enter показана подсказка удалить четыре пробела. Выполнены четыре Backspace, `left()` и Enter — следующая строка не содержит пробелов. Ввод `jump()` завершил образец с точностью 100%.
- Независимое ревью не выявило замечаний; дополнительно проверены вложенный отступ с частичным снятием, ручной повторный ввод автоматического пробела и окончание таймера с оставшимся отступом.

## Предыдущее обновление: автоматический отступ

- После Enter сразу за двоеточием автоматически вставляются пробелы отступа из образца; в случайных алгоритмах их четыре. Автоматические символы не увеличивают скорость и не считаются попытками.
- Добавлены проверки автоматической вставки, удаления и ручного повторного ввода пробела, сохранения отступа на паузе, завершения образца и точных метрик. До реализации проверки падали на отсутствии отступа; после реализации все **52 теста в 6 файлах** проходят.
- В настоящем браузере введены `for i in range(2):` и Enter: поле содержит `for i in range(2):\n    `, курсор стоит в позиции 23 перед `g`. Без ручного набора четырёх пробелов приняты `go()`, Enter и `left()`: готов один образец, точность 100%.
- TypeScript и production-сборка Vite завершились успешно. Ключ рекорда изменён только для условий, где используется автоматический отступ.
