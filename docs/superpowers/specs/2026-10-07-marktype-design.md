# МШП · Код на скорость

Основание: полное пользовательское задание, 7 октября 2026. Новый локальный проект React + TypeScript + Vite. Основной сценарий: настройка → отсчёт 3–2–1 → перепечатывание → результат. Реализация в указанной пустой папке; Git-репозитория и существующего кода нет.

## Продукт и оформление

Только клавиатурный тренажёр. Никакого исполнения кода, задач, регистрации или сетевых зависимостей во время тренировки. На актуальном informatics.ru просмотрены главная страница и вычисленные стили: синие фоны и акценты, округлые заголовки DIN 2014 Rounded, интерфейс Ubuntu, заметные кнопки. Для компактного тренажёра — светлый голубоватый фон, белые карточки, синие действия, округлый локально поставляемый Nunito и моноширинный код; без рекламной структуры и имитации логотипа. Текстовая подпись «МШП · Код на скорость».

Три доступных набора, длительность 30/60/120 секунд (по умолчанию Команды/60). Демонстрационный каталог: go() и его последовательности 2–6 строк. Свой текст нормализуется CRLF→LF, Tab→4 пробела, показывается целиком до запуска. Значимые пробелы сохраняются. История, рекорд при выбранных условиях и очистка доступны отдельно.

## Архитектура

- `src/data/catalog.ts`: точные образцы и метаданные; отдельный файл ожидающих сверки команд.
- `src/engine/session.ts`: независимый движок, монотонные часы, последовательная проверка, неизменяемый снимок для React.
- `src/engine/input.ts`: обработка KeyboardEvent.key, одна точка начисления; служебные клавиши/автоповтор игнорируются.
- `src/engine/deck.ts`: перемешивание без повтора текста на границе.
- `src/storage.ts`: безопасное локальное хранение настроек, последних 20 результатов и рекордов по точным условиям; без сохранения каждого нажатия и исходного пользовательского кода.
- `src/components/*`: настройка, тренировка, результат, история, иконки.

В тренировке используется настоящее textarea с доступным названием и фокусом. keydown — единственный источник зачтённых символов, input не начисляет их. Вставка и drop блокируются только здесь. Каждый пробел/перенос вводится отдельно, Backspace уменьшает текущий префикс. После полного совпадения следующий образец открывается автоматически. Навигация Tab не блокируется.

Скорость = (символы завершённых образцов + текущий префикс) / активные минуты. Точность = правильные попытки / все попытки × 100. Ошибки не удаляются. Таймер и каждый ввод сверяют истёкшее время, поэтому ввод на границе завершения не принимается. Пауза по Esc, кнопке, blur окна, hidden вкладке; затем только ручное продолжение с отсчётом. Образец скрыт на паузе/отсчёте. Длинные строки и текущая позиция прокручиваются внутри зон.

## Проверка

Vitest: движок, границы времени, пауза, метрики, каталог, перемешивание, хранилище. React Testing Library: реальное поле, блокировка вставки, отсутствие двойного ввода, автоповтор, фокус, полный сценарий. Браузер: полный сценарий и размеры 1366×768, 1024×768, узкий экран. TypeScript и production build. README фиксирует реальные результаты и ограничения.
