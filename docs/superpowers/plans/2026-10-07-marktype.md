# МШП · Код на скорость — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Полностью работающий статический клавиатурный тренажёр по пользовательскому заданию.
**Architecture:** Независимый тестируемый движок, каталог данных, безопасное локальное хранение и React-интерфейс.
**Tech Stack:** React, TypeScript, Vite, Vitest, Testing Library.
**Spec:** `docs/superpowers/specs/2026-10-07-marktype-design.md`.

## Global Constraints
- Русский интерфейс, точный текст go(), отсутствие выдуманных команд.
- Без сервера, исполнения кода, аналитики, внешних runtime-сервисов.
- 30/60/120 секунд, отсчёт 3 секунды, история 20 результатов.
- Настоящее поле, самостоятельный ввод каждого символа, точные метрики.

## Review Focus
- Ввод ровно в момент истечения таймера отвергается до React-перерисовки.
- Потеря фокуса на отсчёте и повторная пауза не запускают часы в фоне.
- Одинаковые тексты с разными id не обходят защиту от повтора.
- Повреждённое или недоступное хранилище не мешает тренировке.
- Длинный пользовательский текст и служебные сочетания не ломают ввод/навигацию.
